# Captionify

## Русский

Captionify — приложение для Android и iOS, которое позволяет добавлять текст под фотографиями, сохранять результат и делиться им.

В этом репозитории размещена публичная [политика конфиденциальности Captionify](https://chilcotinn.github.io/captionify-privacy/#russian).
